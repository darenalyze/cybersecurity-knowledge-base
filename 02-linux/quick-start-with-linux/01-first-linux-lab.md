I open the Xfce terminal using gui (mouse). They are using Xfce environment. I am already familiar at the Xfce environment so I am expecting that this will be easy for me. After the terminal popup, the guider tells me to use `echo` command.

`echo`: Command is simply tells the terminal repeate the text you type inside the quotation mark after the command.

I tried it passively to gain muscle memmory out of it. I simply typed `echo  Hello LabEx` and the terminal outputs the "Hello LabEx".

Remember:

- Linux is case-sensitive: `echo`, `Echo`, and `ECHO` are all different.
- Spaces matter. Make sure there is a space between `echo` and the quotation mark (`"`).
- The quotes tell `echo` precisely what string of text to repeat.

### Displaying User and Group Information
`id`: Command is a way to see what group thet specific user belong
`id root`: Is a command to check the id of the superuser(root).

**uid**: Your User ID (a unique numerical identifier).
**gid**: Your primary Group ID.
**groups**: All the groups you are a member of.

root is the superuser – like the administrator of the system!
