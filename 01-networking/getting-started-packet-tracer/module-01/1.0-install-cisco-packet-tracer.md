# 1.0 Install Cisco Packet Tracer

---

## Course Overview & Purpose

**Cisco Packet Tracer** is a visual simulation tool used to model, configure, and troubleshoot network topologies, IoT systems, and cybersecurity setups without needing physical hardware.

* **Key Role:** Supplemental sandbox to practice configuring routers, switches, and end devices.
* **Course Structure:**
  * **Module 1:** Installation, setup, and interface navigation.
  * **Module 2:** Building simulated networks, device configuration, and managing PT file types.
