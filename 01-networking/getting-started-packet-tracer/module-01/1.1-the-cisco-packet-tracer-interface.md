# 1.1 The Cisco Packet Tracer Interface

---

## Device Configuration Tabs

When clicking a device in Packet Tracer, these main tabs appear:

| Tab | Function | Real-World Equivalence |
|---|---|---|
| **Physical** | Add/remove modules (NICs) and toggle power switches | Hands-on physical gear management |
| **Config** | Easy GUI text fields for basic setup | Converts GUI inputs into background IOS commands |
| **CLI** | Type direct Cisco IOS commands | Direct serial/SSH console access |
| **Desktop** | Access terminal, web browser, and IP settings | PC/Laptop OS desktop interface |
| **Services** | Turn on server roles (HTTP, DHCP, DNS) | Server operating system services |

---

## Workspace Modes & Wiring Closet

```text
[ Logical Mode (Shift+L) ]   ---> Focuses on IP layout and connection topology
[ Physical Mode (Shift+P) ]  ---> Focuses on real-world placement (Cities, Racks, Shelves)
```

* **Rack:** Holds mounted networking equipment (routers, switches, patch panels).
* **Table:** Holds active end-user devices (PCs, laptops).
* **Shelf:** Storage area for spare or backup hardware not yet deployed.

---

## Step-by-Step IOS Hostname Commands

```
Router> enable
Router# configure terminal
Router(config)# hostname Edge_Router_Backup
Edge_Router_Backup(config)# end
```

* `enable` -> Enters Privileged EXEC mode.
* `configure terminal` -> Enters Global Configuration mode.
* `hostname [name]` -> Sets the device identification name.
