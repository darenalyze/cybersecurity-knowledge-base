It provides three main menus that you can use for the following:

### 1.1.3 GUI and CLI Configuration in Cisco Packet Tracer
Packet Tracer also provides a variety of tabs for device configuration including the following:
- Physical
- Config
- CLI
- Desktop
- Services

"**Note:** You may see other tabs on different devices. These additional tabs are beyond the scope of this course."

#### Physical Tab

The Physical tab interface for interacting with the device including powering, installing different modules, such as a wireless network interface card (NIC).

#### Config Tab
The tab gives you simple text boxes, buttons, and drop-down menus to setup your device

#### CLI Tab
CLI tab stands for **Command Line Interface tab**. CLI  tab is where you type exact text commands to tell the device what to do. The Config tab does not simulate the functionality of a device.

When you type a setting into the Config tab (like an IP address or a device name), Packet Tracer takes that input, automatically converts it into Cisco commands, and applies them to the router or switch in the background.

#### Desktop Tab
For some end devices, such as PCs and laptops, Packet Tracer provides a desktop interface that gives you access to IP configuration, wireless configuration, a command prompt, a web browser, and other applications.

#### Service Tab
A server has all of the functions of a host with the addition of one more tab, the Services tab. This tab allows a server to be configured with common server processes such as HTTP, DHCP, DNS, or other services.

### 1.1.4 Video - Packet Tracer Tutored Activity
In a Packet Tracer Tutored Activity (PTTA), you will be guided through the activity depending on the hint level you choose. You can choose and change the hint level you want at any time during the activity. The PTTA hint system will support you as you learn.

Note: Not all Packet Tracer activities are PTTAs. Other types of Packet Tracer activities do not have this hinting system.
