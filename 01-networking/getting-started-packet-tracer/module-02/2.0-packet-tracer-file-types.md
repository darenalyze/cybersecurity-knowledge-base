# 2.0 Packet Tracer File Types

## File Formats (.pka, .pkt, .pksz, .pkz)

```
[ .pka ] ---> Activity File (Instructions + Auto-Scoring)
[ .pkt ] ---> Blank Lab File (Raw Network Topology)
[ .pksz] ---> Tutored File (Includes Step-by-Step Hints)
[ .pkz ] ---> Old Archive (DEPRECATED - Do Not Use)
```

*   **`.pka` (Activity File):**
    *   **Core:** Main assignment file with instructions.
    *   **Features:** Displays completion score (0–100%) and has a "Check Results" button.
    *   **Behind the Scenes:** Contains **two** networks (the student network you see, and a hidden answer key running in the background).
*   **`.pkt` (Network File):**
    *   **Core:** Basic file created when saving a network topology.
    *   **Features:** No instructions, no auto-grading. Can store background map images.
*   **`.pksz` (Tutored Activity):**
    *   **Core:** Enhanced `.pka` file.
    *   **Features:** Bundles hints, media, and scripts to guide you through tough steps.
*   **`.pkz` (Archive File):**
    *   **Core:** Outdated file type previously used to pack external images/files.
    *   **Status:** **Deprecated** (Modern `.pkt` / `.pka` files handle media directly).

> **Security Note:** Treat unknown `.pka` or `.pksz` files like executable scripts. Only open lab files from trusted instructors or official sources, as modified activity files can trigger unexpected local scripts or malicious redirects.

## Assessment Types

| Type | Full Name | How it Works | Where it Appears |
| :--- | :--- | :--- | :--- |
| **PTMO** | Packet Tracer Media Object | Open a `.pkt` or `.pka` to investigate/configure, then answer related quiz questions. | Quizzes & Module Exams |
| **PTSA** | Packet Tracer Skills Assessment | Standalone hands-on exam that auto-grades your practical network configuration skills. | Mid-terms & Final Exams |

> **Security Note:** In practical exams (PTSAs), integrity checks are active. Avoid altering hidden file metadata or loading pre-saved running configurations, as assessment engines flag hash mismatches as academic dishonesty.
