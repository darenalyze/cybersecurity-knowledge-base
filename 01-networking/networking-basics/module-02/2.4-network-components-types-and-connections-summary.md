# 2.4 Network Components, Types, and Connections Summary

---

## Module Core Concepts

| Topic | Key Concept | Practical Takeaway |
|---|---|---|
| **Clients & Servers** | Determined by installed software | Dedicated servers handle heavy traffic; P2P works well for small, simple networks. |
| **P2P Networks** | Devices act as both client and server | Low cost and easy setup, but lacks centralized security and scalability. |
| **Network Components** | End Devices, Intermediaries, Media | End devices initiate/receive data; intermediary devices direct and secure the flow. |
| **ISP Connections** | Home-to-Internet link | Options range from wired (DSL, Cable, Fiber) to wireless (Cellular, Satellite). |

> **Security Note:** Wireless integrated routers at the network edge serve as the primary security barrier (firewall/NAT) between private end devices and public ISP connections.

## Quiz Mistakes & Key Corrections

Reviewing the missed questions from the 1st attempt:

* **Question 3 (DSL vs. Cable):**
  * *Missed:* Cable modem
  * *Correct Answer:* **DSL (Digital Subscriber Line)**
  * *Why:* DSL provides high-speed digital transmission specifically over standard copper **phone lines**. Cable uses coaxial TV lines.
* **Question 5 (ISP Function):**
  * *Missed:* Responsible for providing security on private networks
  * *Correct Answer:* **Responsible for providing the link between a private network and the internet**
  * *Why:* ISPs provide connectivity; individual users or companies are responsible for their own internal network security.
* **Question 10 (P2P Application Characteristic):**
  * *Missed:* Each device can act as client/server but not simultaneously
  * *Correct Answer:* **Each device using the application provides a user interface and runs a background service**
  * *Why:* P2P apps run a background service allowing them to send and receive data at the *exact same time*.

## Quick Review Reference

* **End Devices:** Originate data and act as the human-network interface (PCs, Tablets, IP Cameras).
* **Intermediary Devices:** Firewalls, switches, and routers that route and filter network traffic.
* **Satellite Internet:** The best choice for remote areas lacking mobile towers or physical cables.
