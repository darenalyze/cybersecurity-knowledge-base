# 2.2 Network Components

---

## Infrastructure Categories

Network hardware falls into three core categories:

| Category | Role | Examples |
|---|---|---|
| **End Devices (Hosts)** | Source or destination of network messages | PCs, Laptops, Smartphones, Printers, Security Cameras |
| **Intermediary Devices** | Connects end devices and directs traffic across the network | Routers, Switches, Wireless Access Points, Firewalls |
| **Network Media** | The physical path data travels through | Copper wire (LAN), Fiber-optic cable (WAN), Radio waves (Wireless) |

---

## How End Devices Work

* **Host Identification:** End devices use unique addresses (like IP addresses) so the network knows where to send data.
* **User Interface:** End devices are the direct point of contact for human users (sending emails, opening web pages, capturing video).

> **Security Note:** Every end device (like an IP camera, mobile tablet, or printer) has an IP address, making it a potential entry point or target for scanning on an enterprise network.

---

## Quick Quiz Notes
- **Smartphones and Tablets:** Ideal mobile end devices using wireless media for remote internet access.
- **Wireless Router:** An intermediary device used to connect home networks directly to a cable modem or ISP line.
- **End Devices vs. Intermediary Devices:** End devices sit at the edge of the network (source/destination), while intermediary devices sit in the middle to route traffic.
