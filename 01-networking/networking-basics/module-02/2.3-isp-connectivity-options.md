# ISP Connectivity Options

---

## What is an ISP?

An **Internet Service Provider (ISP)** provides the link between your local network and the global internet. 

* **The Internet Backbone:** A high-speed network of underwater and underground **fiber-optic cables** connecting major cities and continents.
* **ISP Services:** Besides internet access, ISPs often offer web hosting, email accounts, domain registration, and cloud backup.

---

## Home Connection Methods

| Method | Physical Line | Characteristics |
|---|---|---|
| **Cable** | Coaxial cable (TV line) | High bandwidth, always-on, shares line with cable TV |
| **DSL** | Copper telephone wire | Uses 3 channels (voice, download, upload); speed drops with distance from ISP office |
| **Fiber** | Fiber-optic cable | Highest speed and bandwidth; common in modern metropolitan areas |
| **Cellular** | Radio waves (Cell towers) | Mobile access anywhere with signal; usually metered with data caps |
| **Satellite** | Line-of-sight dish | Great for rural areas without cable/DSL; requires clear line-of-sight to sky |
| **Dial-Up** | Standard phone line | Extremely slow, low bandwidth; requires dialing a phone number to connect |

---

## Router vs. Direct Modem Connection

Connecting a computer directly to a standalone modem leaves it completely exposed to public internet traffic.

```text
[ Computer ] <---> [ Wireless Integrated Router ] <---> [ Modem / ISP ]
                      (Firewall & Security)
```

> **Security Note:** Connecting an end device directly to an ISP modem without a protective router or firewall exposes every open port on your machine directly to the public internet, making it an easy target for automated port scanners and exploits.

## Quick Quiz Notes
- **Cable Internet:** Delivers high-bandwidth internet over the same coaxial network used for cable TV.
- **DSL (Digital Subscriber Line):** Uses existing landline telephone wires split into separate voice and data channels.
- **Cellular Data:** Transmits internet data using mobile phone tower networks.
