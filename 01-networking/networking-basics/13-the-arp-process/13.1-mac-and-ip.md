# MAC and IP

Devices use **two main addresses** to communicate:

* **MAC Address (Layer 2 / Physical):** Moves data from **NIC to NIC** on the **same local network**.
* **IP Address (Layer 3 / Logical):** Identifies the original **Source** and final **Destination** across any network.

## Destination on Same Network

**Rule:** If the target IP is on the **same local network**, the **Destination MAC** is the **Target Device's MAC**.

| Header Layer | Address Type | Value |
| :--- | :--- | :--- |
| **Layer 2 (Frame)** | **Source MAC** | Sender Device |
| | **Destination MAC** | Target Device |
| **Layer 3 (Packet)** | **Source IP** | Sender Device |
| | **Destination IP** | Target Device |

### EXAMPLE: Same Network Packet Delivery
PC1 sends data to PC2 on the same network:

* **Layer 2 Header:**
  * **Src MAC:** `aa-aa-aa` (PC1)
  * **Dest MAC:** `55-55-55` (PC2)
* **Layer 3 Header:**
  * **Src IP:** `192.168.10.10` (PC1)
  * **Dest IP:** `192.168.10.11` (PC2)

## Destination on Remote Network

**Rule:** If the target IP is on a **different network**, the **Destination MAC** is the **Default Gateway (Router) MAC**.

### How Routers Handle Frames
1. **Receive:** Router receives the frame and removes the Layer 2 header.
2. **Lookup:** Router checks the **Destination IP** to find the next path.
3. **Re-pack:** Router adds a **NEW Layer 2 header** with new MAC addresses for the next jump.

> **Key Rule:** IP addresses **never change** end-to-end, but MAC addresses **change at every router jump**.

### Visualizing Address Changes

```
[ PC1 ] ---> (Switch) ---> [ Router R1 ] ---> [ Router R2 ] ---> [ PC2 ]
```

* **PC1 to Router R1:**
  * **Dest MAC:** R1 Interface MAC
  * **Dest IP:** PC2 IP
* **Router R1 to Router R2:**
  * **Src MAC:** R1 Outgoing Interface MAC
  * **Dest MAC:** R2 Incoming Interface MAC
  * **Dest IP:** PC2 IP (Unchanged)

### EXAMPLE: Remote Network Address Mapping
PC1 sends data to PC2 on a remote network through Router R1 and R2:

* **Link 1 (PC1 to R1):**
  * **Src MAC:** PC1 MAC
  * **Dest MAC:** R1 G0/0/0 MAC
* **Link 2 (R1 to R2):**
  * **Src MAC:** R1 G0/0/1 MAC
  * **Dest MAC:** R2 G0/0/1 MAC

### Address Discovery Protocols
Devices use these protocols to find unknown MAC addresses:

* **IPv4:** **ARP** (Address Resolution Protocol)
* **IPv6:** **ICMPv6 ND** (Neighbor Discovery)
