# 5.3 Network Communication Models

---

## TCP/IP Protocol Stack Highlights

Network communications rely on multiple protocols working together in a stack:

| Protocol | Full Name | OSI Layer | Primary Function |
|---|---|---|---|
| **HTTP** | Hypertext Transfer Protocol | Application (L7) | Exchanges HTML web page content between client and server. |
| **TCP** | Transmission Control Protocol | Transport (L4) | Ensures reliable delivery; sequences and reassembles out-of-order segments. |
| **IP** | Internet Protocol | Network (L3) | Handles end-to-end routing across networks using IP addresses. |
| **Ethernet** | Ethernet Protocol | Data Link / Physical (L2/L1) | Delivers frames between local Network Interface Cards (NICs) on the same LAN. |

---

## OSI vs. TCP/IP Model Mapping

* **Reference Model (OSI):** Conceptual 7-layer framework by ISO describing network functions without mandating specific protocols.
* **Protocol Model (TCP/IP):** Practical 4-layer model structured directly around the active TCP/IP protocol suite.

```
       OSI MODEL (7 Layers)               TCP/IP MODEL (4 Layers)
┌─────────────────────────────────┐     ┌─────────────────────────┐
│ 7. Application                  │ ──┐ │                         │
│ 6. Presentation                 │ ──┼─┤ Application             │
│ 5. Session                      │ ──┘ │                         │
├─────────────────────────────────┤     ├─────────────────────────┤
│ 4. Transport                    │ ────┤ Transport               │
├─────────────────────────────────┤     ├─────────────────────────┤
│ 3. Network                      │ ────┤ Internet                │
├─────────────────────────────────┤     ├─────────────────────────┤
│ 2. Data Link                    │ ──┐ │                         │
│ 1. Physical                     │ ──┴─┤ Network Access          │
└─────────────────────────────────┘     └─────────────────────────┘
```

---

## Quick Quiz Notes

* **TCP:** Guarantees reliable delivery, error recovery, and data reordering at OSI Layer 4.
* **IP:** Used by routers to forward packets across different networks at OSI Layer 3.
* **Network Access Layer:** The single TCP/IP bottom layer that maps directly to OSI **Data Link (L2)** and **Physical (L1)** layers.
* **IP Addressing:** Operates specifically at Layer 3 (**Network Layer**) of the OSI model.
