# 5.4 Communication Principles

## 1. Network Rules (Protocols)

How devices talk to each other correctly.

*   **Format:** The correct structure/layout of a message.
*   **Size:** Maximum limit of data pieces per send.
*   **Timing:** Speed, turn-taking, and flow control.
*   **Encoding:** Converting data into light, electricity, or radio signals.
*   **Encapsulation:** Adding address headers (Source & Destination) to data.
*   **Pattern:** 
    *   *Request/Response:* Needs receipt confirmation.
    *   *Streaming:* Sends data continuously without checking.

> **Security Note:** Bad actors can tamper with *Encapsulation* headers (like IP Spoofing) to pretend they are a trusted device on your network.

---

## 2. Standards & RFCs

*   **Network Standard:** Universal rules so different brands (Apple, Windows, Android) can communicate.
*   **RFC (Request for Comments):** Official documents managed by **IETF** that track how internet standards are built and updated.

> **Security Note:** Old standards often lack encryption. Always check if a system uses updated protocols (like HTTPS instead of HTTP) defined by modern RFCs.

---

## 3. TCP/IP Model (4 Layers)

| Layer | Name | Main Job | Examples |
| :--- | :--- | :--- | :--- |
| **4** | **Application** | Shows data to user | HTTP, FTP, SSH |
| **3** | **Transport** | Manages connection & data split | TCP, UDP |
| **2** | **Internet** | Finds best path across networks | IP, ICMP |
| **1** | **Network Access** | Hardware, cables, and media rules | Ethernet, Wi-Fi |

> **Security Note:** Firewalls inspect traffic at different TCP/IP layers. A simple packet filter looks at **Internet** (IP), while web application firewalls (WAF) inspect **Application** data.

---

## 4. OSI Model (7 Layers)

Visual framework used to design and troubleshoot networks.

```
+-------------------------------------------------+
| 7. Application   -> User apps (Browser, Email)  |
| 6. Presentation  -> Format, Encryption, Zip     |
| 5. Session       -> Starts & stops connections  |
| 4. Transport     -> Segments data (TCP/UDP)     |
| 3. Network       -> IP Routing                  |
| 2. Data Link     -> MAC Addresses, Switches     |
| 1. Physical      -> Cables, Binary Bits (0/1)   |
+-------------------------------------------------+
```

### Layer Details

*   **7 - Application:** Interface for user software.
*   **6 - Presentation:** Data formatting and encryption.
*   **5 - Session:** Manages dialogue between apps.
*   **4 - Transport:** Splits, moves, and recombines data.
*   **3 - Network:** Routes data pieces using logical IP addresses.
*   **2 - Data Link:** Moves data frames over physical media using MAC addresses.
*   **1 - Physical:** Raw electrical or light bits (1s and 0s).

> **Security Note:** Attacks happen at specific OSI layers. For example, a **DDoS attack** can flood Layer 3/4 with bandwidth traffic, or flood Layer 7 with web requests to crash a server.
