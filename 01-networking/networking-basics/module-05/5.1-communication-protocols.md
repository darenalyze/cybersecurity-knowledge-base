# 5.1 Communication Protocols

## Human vs. Network Protocols

Communication requires agreed-upon rules whether between humans or computing devices. Both environments rely on identical foundational principles to establish a working link:

| Fundamental Requirement | Human Analogy | Network Technical Implementation |
|---|---|---|
| **Identified Endpoints** | Sender and receiver (e.g., Bianka and Nguyệt) | Source & Destination IP addresses / MAC addresses |
| **Method** | Verbal, written notes, sign language | Copper wire, fiber-optic light, RF radio waves |
| **Language & Encoding** | English, Japanese, Spanish | Binary encoding (0s and 1s into electrical signals, light pulses, or radio frequencies) |
| **Confirmation / Acknowledgment** | Repeating directions back: *"Yes, that is correct"* | TCP 3-way handshake, ACKs (acknowledgments) |

---

## Core Protocol Characteristics

Networking protocols standardize six main characteristics to ensure reliable data transfer across local networks:

| Characteristic | Primary Function | Real-World Network Example |
|---|---|---|
| **Message Format** | Dictates the exact structural layout of a frame or packet. | Ordering header fields (e.g., Destination MAC listed before Source MAC). |
| **Message Size** | Breaks long streams into manageable chunks (segmentation/fragmentation). | Ethernet Frame Size limits (**64 to 1518 bytes**). |
| **Timing** | Manages flow control, transmission speed, and response timeouts. | Clock rates, collision avoidance, and retransmission timers. |
| **Encoding** | Converts binary bits into physical signals suitable for the medium. | Voltage changes on UTP copper, light pulses in glass fiber, or modulated radio signals in Wi-Fi. |
| **Encapsulation** | Wraps raw data with control headers and trailers containing addressing/metadata. | Adding IP and MAC headers to an application data payload. |
| **Message Pattern** | Governs interaction styles between endpoints. | **Request/Response** (TCP / HTTP with ACKs) vs. **Unidirectional Streaming** (UDP / live video streams). |
