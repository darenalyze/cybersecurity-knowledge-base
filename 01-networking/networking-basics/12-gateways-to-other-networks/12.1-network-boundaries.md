# Network Boundaries

## Gateways to Other Networks

A **Default Gateway** is the **exit door** for network traffic leaving a local network to reach the internet or remote networks.

### How Traffic Leaves the Network
* **Same Network (Local):** Device sends data directly to the destination.
* **Different Network (Remote):** Device sends data directly to the **Default Gateway**.
* **Finding the Gateway:** The device uses **ARP** to find the physical **MAC address** of the Default Gateway.

### Simple Visualization
[ Local Host ] ---> [ Default Gateway (Router) ] ---> [ Internet ]

### EXAMPLE: Wrong Subnet Error
> If a host IP is `192.168.1.10`, but its Gateway is accidentally set to `192.168.11.1` (different network), the host **cannot use ARP** to find the gateway and **loses internet access**.


## Routers as Gateways

A router connects different networks together. **Each router interface is its own separate network.**

### Network Configuration Package
To communicate outside the local network, every host needs 3 key settings from a **DHCP Server**:
* **IPv4 Address:** Device ID on the local network.
* **Subnet Mask:** Defines local network boundaries.
* **Default Gateway:** The IP address of the local router port.

### EXAMPLE: Department Gateways
> * **Management Department:** Connects to Router Port A (`192.168.1.1`) -> Gateway is `192.168.1.1`.
> * **Accounting Department:** Connects to Router Port B (`192.168.2.1`) -> Gateway is `192.168.2.1`.
> Devices in different departments use **different default gateways** because they sit on different router ports.


## Routers as Network Boundaries

A wireless router sits as a **boundary** separating the local private network from the public internet.

### Internal vs. External Networks

* **Internal Network (Inside / LAN):**
  * Your local devices (PCs, phones, TVs).
  * Router acts as a **DHCP Server**, handing out **Private IP addresses**.
  * Security Note: *Private IPs block direct inbound connections from the internet, protecting local devices from outside hackers.*

* **External Network (Outside / WAN):**
  * The internet side connected to the ISP.
  * Router acts as a **DHCP Client**, receiving an **Internet-Routable Public IP** from the ISP.

### Summary of Router Roles
* **Facing Inside:** Acts as **DHCP Server** (gives Private IPs to home devices).
* **Facing Outside:** Acts as **DHCP Client** (gets Public IP from ISP).
