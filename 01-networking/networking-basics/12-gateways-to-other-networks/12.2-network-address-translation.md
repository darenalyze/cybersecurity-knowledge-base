# Network Address Translation

## IP Address Types

IP addresses have **two categories**:

*   **Private IP:** Used **inside** a local network (home or office). It **cannot** travel across the internet.
*   **Public IP:** Registered address used to travel across the **public internet**.

security note: *Private IPs hide your internal devices from the public internet, adding a basic layer of protection against direct outside attacks.*

### Private IP Ranges

*   **192.168.x.x:** Used for **small networks** and home setups (supports up to 254 devices).
*   **172.16.x.x:** Used for **medium networks**.
*   **10.x.x.x:** Used for **large networks** and big companies.

## What is NAT

**NAT (Network Address Translation)** is a router feature. It swaps a **Private IP** with a **Public IP** so internal devices can access the internet.

*   **NAT Table:** A list inside the router that tracks which **Private IP** matches which **Public IP**.

### Simple NAT Flow

`[ Local Device (Private IP) ] ---> [ Router (NAT Table) ] ---> [ Internet (Public IP) ]`

## How NAT Works

### Outbound (Sending Data)
1. Device sends data with its **Private IP** as the source.
2. Router replaces the **Private IP** with a **Public IP**.
3. Router saves this connection in its **NAT Table**.
4. Router sends the data to the internet.

### Inbound (Receiving Data)
1. Internet server replies to the router's **Public IP**.
2. Router checks its **NAT Table** to find the matching device.
3. Router changes the destination back to the device's **Private IP**.
4. Router delivers the data to the device.

## Example - NAT Packet Flow

### Example Scenario Setup
*   **PC Private IP:** `192.168.1.15`
*   **Router Public IP:** `200.100.58.51`
*   **Web Server IP:** `210.100.5.5`

### Example Packet Journey

1. **PC sends data out:**
   * **Source:** `192.168.1.15`
   * **Destination:** `210.100.5.5`

2. **Router translates packet:**
   * **Source:** `200.100.58.51` (Changed by NAT)
   * **Destination:** `210.100.5.5`

3. **Web Server replies back:**
   * **Source:** `210.100.5.5`
   * **Destination:** `200.100.58.51`

4. **Router translates packet back to PC:**
   * **Source:** `210.100.5.5`
   * **Destination:** `192.168.1.15` (Changed back by NAT)
