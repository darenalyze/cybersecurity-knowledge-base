# Clients and Servers

---

## Client vs. Server Roles

Hosts on a network act as clients, servers, or both, depending on the software installed:

| Role | Function | Software Example |
|---|---|---|
| **Server** | Provides resources and information to other hosts | Apache/Nginx (Web), Exchange (Email) |
| **Client** | Requests and displays information from servers | Chrome/Firefox (Browser), Outlook (Email) |

Common server types include **Email Servers**, **Web Servers**, and **File Servers**. A single powerful machine can run multiple server applications at once.

---

## Peer-to-Peer (P2P) Networks

In a P2P network, devices act as both client and server at the same time to share files and resources directly.

```text
[ Device A ] <---> [ Switch ] <---> [ Device B ]
  (Client/Server)                     (Client/Server)
```

| Pros | Cons |
|---|---|
| Easy to set up & low cost | No centralized administration |
| No dedicated server needed | Weaker security & lower scalability |
| Good for simple file/printer sharing | High traffic slows down host devices |

---

## P2P Applications & Hybrid Systems

* **P2P Apps:** Every device runs a background sharing service alongside its user interface.
* **Hybrid Systems:** Index/search directories are kept on a central server, but actual file downloads happen directly between peers (e.g., BitTorrent indexing).

> **Security Note:** P2P networks and applications are heavily targeted in underground markets. Distributing malware via P2P file shares is common, and lack of centralized administration makes tracking malicious host behavior difficult.

---

## Quick Quiz Notes
- **Server:** Host software designed to provide data/services to other network devices.
- **Client:** Host software (like a web browser) designed to request data from servers.
- **Peer-to-Peer Network:** A setup where two or more hosts communicate simultaneously as both clients and servers.
