# Communication Standards


## The "Device in a Bubble" Concept

Devices have zero physical awareness of the network topology. They rely on protocols to answer 5 fundamental questions:

* **What is my IP address?** $\rightarrow$ **DHCP / ICMPv6** assigns local IP settings.
* **Is the target local or remote?** $\rightarrow$ **IP / Subnet Mask** compares local vs. destination address.
* **Where do remote packets go?** $\rightarrow$ **Default Gateway** routes traffic outside the local network.
* **How do I find a server's IP?** $\rightarrow$ **DNS** translates domain names to IP addresses.
* **Did my data arrive safely?** $\rightarrow$ **TCP / ICMP** tracks acknowledgments, retransmissions, and errors.


## Internet Standards & IETF

* **Standards:** Universal rules ensuring different devices (PCs, phones, servers) can talk to each other seamlessly.
* **IETF:** Internet Engineering Task Force; the main organization that develops and manages internet standards.
* **RFC (Request for Comments):** Numbered technical documents published by the IETF to track, test, and formalize protocol specifications.


## Quick Quiz Notes

* **Protocols:** The overall rules governing message format, size, timing, and encapsulation across a network.
* **RFCs:** Official IETF documents used to record and publish internet standards.
