# Network Communication Models

---

## The OSI 7-Layer Reference Model

The **OSI Model** breaks network communication into 7 distinct steps. Each layer has a specific job, uses its own type of addressing, and wraps data inside its own container called a **PDU (Protocol Data Unit)**.

```text
               OSI MODEL (7 Layers)
┌──────────────────────────────────────────────────┐
│ 7. Application   -> User Interface & Services     │
│ 6. Presentation  -> Data Format, Encryption, Zip │
│ 5. Session       -> Connection Management        │
├──────────────────────────────────────────────────┤
│ 4. Transport     -> Segments, Ports, Reliability │
├──────────────────────────────────────────────────┤
│ 3. Network       -> Packets, IP Routing          │
├──────────────────────────────────────────────────┤
│ 2. Data Link     -> Frames, MAC Addresses        │
│ 1. Physical      -> Bits (0s & 1s), Cables       │
└──────────────────────────────────────────────────┘
```

---

## Detailed Layer-by-Layer Breakdown

### Layer 7: Application Layer
* **Main Job:** Acts as the window for software applications to access network services. It directly interacts with user software.
* **Key Protocols:** HTTP/HTTPS (Web browsing), FTP (File transfer), SSH/Telnet (Remote access), DNS (Domain lookup), SMTP/IMAP (Email).
* **Security Note:** Target of **Layer 7 DDoS attacks** (e.g., overwhelming a web server with HTTP requests) and SQL Injection. Protected by Web Application Firewalls (WAF).

---

### Layer 6: Presentation Layer
* **Main Job:** Translates, formats, encrypts, and compresses data so the receiving computer can understand it. It ensures data from Layer 7 is readable by the destination system.
* **Key Functions:**
  * **Encryption / Decryption:** SSL/TLS security.
  * **Compression:** Reducing file size for transfer (e.g., ZIP, gzip).
  * **Formatting:** Converting data types (e.g., JPEG/PNG for images, ASCII/UTF-8 for text).

---

### Layer 5: Session Layer
* **Main Job:** Opens, maintains, and terminates active connections ("sessions") between two applications on different computers.
* **Key Functions:**
  * **Session Checkpointing:** If a large file download is interrupted, it can resume from the last saved checkpoint instead of starting over.
  * **Dialogue Control:** Determines which side sends data first and how long each side can talk.
* **Key Protocols:** NetBIOS, RPC (Remote Procedure Call), PPTP.

---

### Layer 4: Transport Layer
* **Main Job:** Takes application data, chops it into smaller chunks, and manages end-to-end conversation between applications using **Port Numbers**.
* **PDU Name:** **Segment** (for TCP) / **Datagram** (for UDP).
* **Addressing Used:** **Source & Destination Port Numbers** (e.g., Port 80 for HTTP, Port 443 for HTTPS).
* **Key Protocols:**
  * **TCP (Transmission Control Protocol):** Reliable, connection-oriented. Guarantees delivery, orders segments, and retransmits lost data.
  * **UDP (User Datagram Protocol):** Fast, connectionless. No delivery guarantees (used for streaming and live gaming).

---

### Layer 3: Network Layer
* **Main Job:** Takes segments from Layer 4, performs **Encapsulation** by adding IP headers, and finds the best physical path to route data across different networks.
* **PDU Name:** **Packet**.
* **Addressing Used:** **Source & Destination IP Addresses** (Logical addresses like `192.168.1.1`).
* **Key Protocols & Hardware:** IP (IPv4, IPv6), ICMP (`ping`), Routers, Layer 3 Switches.
* **Security Note:** Attackers manipulate IP headers in **IP Spoofing** attacks to bypass basic firewall rules.

---

### Layer 2: Data Link Layer
* **Main Job:** Encapsulates packets into frames and moves them locally between devices on the same physical network wire or Wi-Fi channel.
* **PDU Name:** **Frame**.
* **Addressing Used:** **Source & Destination MAC Addresses** (Physical addresses burned into hardware NICs, e.g., `AA:BB:CC:DD:EE:FF`).
* **Key Protocols & Hardware:** Ethernet (802.3), Wi-Fi (802.11), Switches, Network Interface Cards (NICs).
* **Sublayers:**
  * **LLC (Logical Link Control):** Talks to the Network layer above.
  * **MAC (Media Access Control):** Controls access to the physical media below.

---

### Layer 1: Physical Layer
* **Main Job:** Converts binary frames from Layer 2 into raw physical signals (electricity, light, or radio waves) and transmits them across physical media.
* **PDU Name:** **Bits (1s and 0s)**.
* **Addressing Used:** None (Hardware / Mechanical layer).
* **Key Hardware:** Ethernet cables (Cat5e/Cat6), Fiber optics, Wi-Fi antennas, Hubs, Repeaters.

---

## Step-by-Step Data Encapsulation Flow

When you send a request over the network, data travels **top to bottom** (Encapsulation). When a server receives it, data travels **bottom to top** (De-encapsulation):

$$\text{User Data (L7-L5)} \xrightarrow{\text{Add Ports}} \text{Segment (L4)} \xrightarrow{\text{Add IPs}} \text{Packet (L3)} \xrightarrow{\text{Add MACs}} \text{Frame (L2)} \xrightarrow{\text{Convert}} \text{Bits (L1)}$$

## TCP/IP Model vs. OSI Model Mapping

While the OSI Model uses 7 layers for theoretical training, the practical **TCP/IP Model** condenses these functions into 4 layers:

| TCP/IP Layer | Corresponding OSI Layers | Main Focus |
| :--- | :--- | :--- |
| **4. Application** | Layer 7 (Application), Layer 6 (Presentation), Layer 5 (Session) | User software, data formatting, and session setup. |
| **3. Transport** | Layer 4 (Transport) | Port addresses, TCP reliability, and UDP speed. |
| **2. Internet** | Layer 3 (Network) | IP addressing, packet creation, and router path determination. |
| **1. Network Access** | Layer 2 (Data Link), Layer 1 (Physical) | MAC addressing, Ethernet frames, cables, and signal transmission. |
