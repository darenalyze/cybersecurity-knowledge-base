# Purpose of an IPv4 Address

## The IPv4 Address

An **IPv4 address** is a unique logical label assigned to a device on a network.

* **Unique ID:** Every device needs a unique address to talk on a local network (**LAN**) or the **Internet**.
* **Where assigned:** Set on the **Network Interface Card (NIC)** (e.g., PCs, servers, printers, router ports).
  * *Note:* Some servers have multiple NICs, so each NIC gets its own IPv4 address.
* **Packet tracking:** Every data packet must have both **Source IPv4** (sender) and **Destination IPv4** (receiver).

### Example: Devices with IPv4 Addresses
* Workstations & Laptops
* Servers
* Network Printers
* IP Phones
* Router Ports

> **Security Note:** Never leave devices with public IPv4 addresses directly open to the internet without a firewall. Hackers actively scan IP addresses for open ports to gain unauthorized access.

## Octets and Dotted-Decimal Notation

An IPv4 address is **32 bits** long in binary (1s and 0s). 

To make it easy for humans to read:
1. The 32 bits are divided into **4 equal groups** called **octets** (8 bits each).
2. Each octet is converted into a **decimal number**.
3. Numbers are separated by **dots**.

### Visual Structure

```text
 [ Octet 1 ] . [ Octet 2 ] . [ Octet 3 ] . [ Octet 4 ]
     209     .     165     .     200     .      1     <-- Dotted-Decimal
  (8 bits)      (8 bits)      (8 bits)      (8 bits)  <-- Total = 32 Bits
```

### Example: Binary to Dotted-Decimal Conversion

* **Raw 32-bit Binary:** `11010001101001011100100000000001`
* **4 Octets (Binary):** `11010001.10100101.11001000.00000001`
* **Dotted-Decimal:** `209.165.200.1`
