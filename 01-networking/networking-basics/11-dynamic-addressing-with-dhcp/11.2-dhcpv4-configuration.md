# DHCPv4 Configuration

## DHCPv4 Operation

DHCP automates IP assignment using **4 basic steps** (often called the **DORA** process).

```
[ Client / Host ]                               [ DHCP Server ]
       | --- (1) DHCP Discover (Broadcast) ----> |
       | <--- (2) DHCP Offer (Unicast/Bcast) --- |
       | --- (3) DHCP Request (Accept) --------> |
       | <--- (4) DHCP ACK (Confirmed) --------- |
```

### The 4-Step Process (DORA)
* **Discover:** Client sends a broadcast packet containing its **MAC address** asking, "Is there a DHCP server?"
* **Offer:** Server responds with an available **IP address**, **Subnet Mask**, and **Default Gateway**.
* **Request:** Client accepts the offer and tells the server, "I will use this IP address."
* **ACK (Acknowledge):** Server binds the IP address to the client's MAC address in its table and confirms the connection.

### Common DHCP Server Devices
* **Home Routers:** Wireless or wired routers.
* **Dedicated Servers:** Business servers (Windows Server, Linux Server).

> Security Note: *Rogue (unauthorized) DHCP servers can trick clients into using a fake Default Gateway, allowing attackers to spy on network traffic (Man-in-the-Middle attack).*

## DHCP Service Configuration

To run DHCP on a network, the router or server needs two main settings:

* **Router LAN IP:** The local IP of the router (acts as the **Default Gateway** for all clients).
* **IP Address Range (Pool):** The set starting address and ending address reserved for clients.

### Enabling DHCP on Clients
* Change host IP settings from **Static** to **DHCP / Automatic**.
* Host immediately sends a request and grabs the **next available IP** in the pool.

### Example: Packet Tracer Wireless Router Setup

#### Router Settings
* **Router LAN IP:** `172.16.0.1` (Serves as Default Gateway)
* **DHCP Pool Start IP:** `172.16.0.100`

#### Client Auto-Assignment Steps
1. **PC 0** switched to DHCP $\rightarrow$ Gets `172.16.0.100` (First available IP)
2. **PC 1** switched to DHCP $\rightarrow$ Gets `172.16.0.101` (Next available IP)
3. **PC 2** switched to DHCP $\rightarrow$ Gets `172.16.0.102` (Next available IP)

#### Testing Connection
* Run `ping 172.16.0.101` from **PC 0** to confirm that automatic addressing worked properly.
