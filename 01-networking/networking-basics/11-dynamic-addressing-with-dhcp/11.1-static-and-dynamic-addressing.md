# Static and Dynamic Addressing

## Static IPv4 Address Assignment

**Static addressing** means a network administrator **manually enters** the network settings into a device.

### Minimum Required Settings
* **IP Address:** Identifies the specific device on the network.
* **Subnet Mask:** Identifies which local network the device belongs to.
* **Default Gateway:** The router address used to access the internet or outside networks.

### Best Used For
* Web servers
* Network printers
* Routers and switches

### Key Highlights
* **Pros:** Full control; address never changes, so clients can always find the device.
* **Cons:** Slow setup; easy to make human typing errors; addresses are permanent and cannot be reused automatically.

> Security Note: *Because static IPs do not change, exposed servers are easier for hackers to target. Always protect static devices behind a firewall.*

## Dynamic IPv4 Address Assignment

**Dynamic addressing** uses **DHCP** (Dynamic Host Configuration Protocol) to assign network settings **automatically**.

```
[ Device / Host ] <--- Auto-assigned IP / Subnet / Gateway --- [ DHCP Server ]
```

### Key Highlights
* **Automatic:** Sends IP address, subnet mask, and default gateway instantly to new devices.
* **Temporary Lease:** IPs are rented for a set time. When a device disconnects, its IP returns to the pool for other devices to reuse.
* **Best Used For:** Laptops, smartphones, guest networks, and large companies.
* **Pros:** Saves support time, stops typing errors, and recycles unused IP addresses efficiently.

> Security Note: *Attackers can set up fake (rogue) DHCP servers to redirect your traffic. Enterprise networks use DHCP Snooping to block unauthorized DHCP servers.*

## DHCP Servers

A **DHCP Server** is any device running DHCP software that distributes IP addresses to client devices.

```
[ Internet / ISP ] ---> Public IP ---> [ Home Wireless Router ] ---> Private IPs ---> [ Phones & Laptops ]
                                          (DHCP Client & Server)
```

### Types of DHCP Servers
* **Dedicated Server:** A physical PC or server machine used in medium-to-large businesses.
* **Home Wireless Router:** Acts as both a **DHCP Client** (gets a public IP from your ISP) and a **DHCP Server** (gives private IPs to your home devices).
* **Network Router / ISP:** Dedicated router hardware or ISP systems handing out IPs directly.

### Example: Connecting to Airport or Coffee Shop Wi-Fi
* **Step 1:** You walk into a coffee shop and join the wireless network.
* **Step 2:** Your device acts as a **DHCP Client** and requests network settings.
* **Step 3:** The local **DHCP Server** automatically leases an IP address to your device.
* **Step 4:** You get instant internet access without typing any network settings.
