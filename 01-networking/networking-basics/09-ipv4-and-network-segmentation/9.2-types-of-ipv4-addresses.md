# Types of IPv4 Addresses

---

## Public and Private IPv4 Addresses

* **Public IPv4 Addresses:** Globally unique. Used to route traffic directly across the public internet.
* **Private IPv4 Addresses (RFC 1918):** Used inside local networks (intranet). Free and reusable, but **cannot route on the internet**.

> **Main Purpose:** Private IPs were created to stop **IPv4 address depletion** (running out of addresses). The permanent fix is **IPv6**.

---

## Routing to the Internet

Internal networks use private addresses, but internet routers drop private IP traffic.

* **NAT (Network Address Translation):** A service on edge routers that translates **Private IPv4** to **Public IPv4** before sending packets to the internet.

```
[ Local Device (Private IP) ] ---> [ Router (NAT Translation) ] ---> [ Internet (Public IP) ]
```

> **Security Note:** Routers must always **drop incoming private IP packets** from the public internet to block spoofing attacks and prevent routing loops.

---

## Special Use IPv4 Addresses

* **Loopback Addresses (`127.0.0.0/8`):** Usually `127.0.0.1`. Used by a device to **send traffic to itself** to test internal network settings and software.
* **Link-Local Addresses (`169.254.0.0/16`):** Also called **APIPA**. A **self-assigned** address used by Windows when a device cannot get an IP address automatically.

### EXAMPLE: Testing Loopback Connection
```text
C:\Users\NetAcad> ping 127.0.0.1
Pinging 127.0.0.1 with 32 bytes of data:
Reply from 127.0.0.1: bytes=32 time<1ms TTL=128
Reply from 127.0.0.1: bytes=32 time<1ms TTL=128
```

## Legacy Classful Addressing

Old system (RFC 790) that divided IPv4 addresses into fixed classes:

| Class | Address Range | Prefix | Host Capacity | Primary Use |
|---|---|---|---|---|
| **Class A** | `0.0.0.0/8` - `127.0.0.0/8` | `/8` | 16 Million+ | Huge Networks |
| **Class B** | `128.0.0.0/16` - `191.255.0.0/16` | `/16` | 65,000+ | Large/Medium Networks |
| **Class C** | `192.0.0.0/24` - `223.255.255.0/24` | `/24` | 254 | Small Networks |
| **Class D** | `224.0.0.0` - `239.0.0.0` | N/A | N/A | **Multicast** |
| **Class E** | `240.0.0.0` - `255.0.0.0` | N/A | N/A | **Experimental** |

* **Main Problem:** **Massive Waste.** Class A used 50% of all IPv4 addresses, leaving millions unused.
* **Modern Solution:** Replaced by **Classless Addressing**, which gives out IP blocks based on exact need instead of rigid classes.

---

## Assignment of IP Addresses

Public IP addresses must be globally unique and are distributed in a chain:

```
[ IANA ] ---> [ RIRs (Regional Registries) ] ---> [ ISPs ] ---> [ End Users / Companies ]
```

* **IANA:** Global authority managing all IP addresses.
* **RIRs (Regional Internet Registries):** 5 regional groups that allocate address blocks to ISPs and large businesses.
