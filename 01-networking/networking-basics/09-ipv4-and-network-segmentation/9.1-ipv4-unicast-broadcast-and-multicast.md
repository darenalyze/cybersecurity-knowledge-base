# IPv4 Unicast, Broadcast, and Multicast

## Unicast

**Unicast** is a **one-to-one** communication from a single sender to a single specific receiver.

* **Communication:** 1-to-1
* **Source Address:** Always a **Unicast** address (a packet can only come from one single device).
* **Destination Address:** Specific to **one device**.
* **Address Range:** `1.1.1.1` to `223.255.255.255` *(excluding reserved addresses)*.
* **Default:** Standard mode for almost all network communications.

### Visual Structure

```text
 [ Sender ]  -------------->  [ Receiver ]
 (172.16.4.1)                (172.16.4.253)
```

### Example: Unicast Transmission
*(Example from Module)*

* **Source IPv4:** `172.16.4.1` (PC)
* **Destination IPv4:** `172.16.4.253` (Printer)
* **Result:** Only the printer receives and processes the packet.

## Broadcast

**Broadcast** is a **one-to-all** communication sent to every device on a local network segment (**broadcast domain**).

* **Communication:** 1-to-All
* **Destination Address:** All binary ones (`1`s) in the host portion.
* **Processing:** **Every host** on the local network must receive and process the packet.
* **Router Action:** Routers **do not forward** broadcasts to other networks by default.
* **Impact:** Excessive broadcasts waste bandwidth and CPU power.

> **Security Note:** Cybercriminals can launch **Broadcast Amplification attacks** (e.g., Smurf Attacks) to flood networks with unwanted traffic. Keep broadcast domains small to limit risk.

### Types of Broadcasts

* **Limited Broadcast:** Destination IP is `255.255.255.255` (sent to all hosts on the local network).
* **Directed Broadcast:** Destination IP has all `1`s in host portion for a specific network (e.g., `172.16.4.255`).

### Visual Structure

```text
                  /---> [ Host A ]
 [ Sender ] ----+-----> [ Host B ]
                  \---> [ Host C ]
```

### Example: Broadcast Transmission
*(Example from Module)*

* **Source IPv4:** `172.16.4.1`
* **Destination IPv4:** `255.255.255.255`
* **Result:** Switch floods packet out all ports; every device processes it, but the connected router stops it from leaving the LAN.

## Multicast

**Multicast** is a **one-to-many** communication sent to a specific group of subscribed hosts (**multicast clients**).

* **Communication:** 1-to-Selected Group
* **Address Range:** `224.0.0.0` to `239.255.255.255`
* **Processing:** Only devices that **subscribe** to the multicast group process the packets; all other hosts ignore them.
* **Efficiency:** Saves bandwidth by sending a single packet stream instead of separate unicast streams.

### Visual Structure

```text
                  /---> [ Group Member ] (Processes packet)
 [ Sender ] ----+-----> [ Non-Member   ] (Ignores packet)
                  \---> [ Group Member ] (Processes packet)
```

### Example: Multicast Transmission
*(Example from Module)*

* **Source IPv4:** `172.16.4.1`
* **Multicast IP Group:** `224.0.0.5` (OSPF Routing Protocol)
* **Target Devices:** `172.16.4.3` and `172.16.4.4`
* **Result:** Only `172.16.4.3` and `172.16.4.4` process the packet because they are in the multicast group. Other devices ignore it.
