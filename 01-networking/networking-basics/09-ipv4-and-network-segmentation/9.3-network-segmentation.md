# Network Segmentation

---

## Broadcast Domains and Segmentation

### What is a Broadcast Domain?
* **Devices ask for help using Broadcasts:** Single messages sent to **ALL** devices on the same local network.
* **Switches:** Forward broadcasts out **ALL** ports (except the incoming port).
* **Routers:** **STOP** broadcasts. They do not forward broadcasts to other networks.

> **Key Rule:** **Routers segment (divide) Layer 2 broadcast domains.**



### Common Broadcast Examples

> **EXAMPLE ONLY (Do not confuse with core definition)**
> * **ARP Request:** "Who has this IP? Send me your MAC address."
> * **DHCP Discover:** "Is there a DHCP server? I need an IP address."



## Problems with Large Broadcast Domains

Connecting too many hosts in one large network causes severe performance issues:

```
[ Too Many Devices ] ---> [ Massive Broadcast Traffic ] ---> [ Slow Network + Slow Devices ]
```

* **High Network Traffic:** Too many devices talking at the same time clogs bandwidth.
* **High CPU Load:** Every device **MUST** open and process every broadcast packet it receives.



## The Solution: Subnetting

**Subnetting:** Splitting one large network into smaller subnets.

### Benefits
* **Better Speed:** Reduces overall network traffic.
* **Contained Issues:** Restricts network problems or malicious traffic to one small area.
* **Enhanced Security:** Enables access controls between subnets.

> Security Note: *Isolate critical servers into their own subnet using firewalls so unauthorized users cannot access sensitive data.*



### Subnetting Example

> **EXAMPLE ONLY (Do not confuse with core definition)**
>
> **Before:**
> * `172.16.0.0 /16` (1 Large LAN = **400 users**)
>
> **After Subnetting:**
> * Subnet 1: `172.16.0.0 /24` (**200 users**)
> * Subnet 2: `172.16.1.0 /24` (**200 users**)
>
> *Result:* Broadcasts in Subnet 1 **NEVER** reach Subnet 2.



## Common Ways to Segment Networks

Administrators group devices using longer prefix lengths based on:

* **Location:** Floor 1, Floor 2, Building A.
* **Group / Function:** Sales, HR, Accounting.
* **Device Type:** Users, Servers, Printers, IP Phones.
