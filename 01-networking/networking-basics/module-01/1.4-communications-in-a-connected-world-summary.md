# Communications in a Connected World Summary

---

## Module Core Concepts

| Topic | Key Concept | Practical Takeaway |
|---|---|---|
| **Network Types** | Interconnected scale (Home, SOHO, Enterprise, Internet) | Networks scale from simple two-device setups to a global "network of networks." |
| **Connected Edge (IoT)** | Smart devices, sensors, medical gear | Every online device expands the network and increases potential entry points. |
| **Data Types** | Volunteered, Observed, Inferred | Data is created directly by you, tracked automatically, or calculated behind the scenes. |
| **Signal Media** | Copper (Electric), Fiber (Optical), Air (Wireless) | Bits travel as electrical pulses, light pulses, or radio waves depending on the physical path. |
| **Speed Metrics** | Bandwidth vs. Throughput | Bandwidth is total capacity; throughput is actual real-world speed minus latency. |

> **Security Note:** Understanding how data travels across different media and device types is essential for tracking data leaks, mapping network entry points, and analyzing malicious traffic patterns.

---

## Quick Review Reference

* **Bit:** The fundamental unit of data (0 or 1).
* **Latency:** Delay time caused by physical distance and intermediate network hardware.
* **Network Reliability:** Like a spiderweb, modern networks use redundant links so traffic can reroute if one connection fails.
