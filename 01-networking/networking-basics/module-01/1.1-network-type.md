# 1.1 Network Types

---

## Network Sizes

| Type | Used For | Example |
|---|---|---|
| **Small Home** | Personal use | Connecting 2-3 phones and a PC to Wi-Fi |
| **SOHO** | Home offices & small shops | Connecting a remote worker to company files |
| **Medium / Large** | Schools & big companies | Hundreds of PCs, multiple floors, main servers |
| **The Internet** | Everyone worldwide | A massive global web connecting all local networks |

---

## Connected Devices & Risks

Modern networks connect more than just computers. Many daily objects now go online:

* **Mobile & Wearables:** Phones, tablets, smartwatches.
* **Smart Home:** Smart TVs, security cameras, smart fridges.
* **Work & Industry:** 
  * **RFID Tags:** Small chips used to track packages in shipping.
  * **Sensors:** Tools that measure temperature, soil water, or weather.
  * **Actuators:** Automatic switches (like turning on a water sprinkler when a sensor detects dry soil).
  * **Medical Devices:** Tools like pacemakers or hospital monitors.

> **Security Note:** Many smart devices (like TVs or cameras) have weak passwords and rarely get updates. Hackers often target these easy devices to enter a network.

- **RFID tags** are placed on packages so companies can track them.
