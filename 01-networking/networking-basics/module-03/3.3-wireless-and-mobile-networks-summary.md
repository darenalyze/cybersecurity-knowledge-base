# 3.3 Wireless and Mobile Networks Summary

---

## Module Core Concepts

| Technology | Scope / Range | Key Characteristics | Common Applications |
|---|---|---|---|
| **Cellular (GSM/4G/5G)** | Wide Area (Towers) | Optimized for fast voice/data transmission across large geographic regions | Phone calls, SMS, mobile data web browsing |
| **Wi-Fi** | Local Area (~30–100m) | Connects to local wireless LANs and hotspots; saves cellular data and battery | High-bandwidth internet access |
| **Bluetooth** | Short Range (~10m) | Low-power, automatic wireless connections for up to 8 devices simultaneously | Hands-free headsets, mice, speakers, tethering |
| **NFC** | Very Short (<4cm) | Ultra-close electromagnetic data transfer requiring close proximity | Tap-to-pay systems, mobile device contact sharing |
| **GPS** | Global (Satellite) | One-way satellite signals received to calculate precise physical position | Map navigation, location tracking |

> **Security Note:** Protecting mobile wireless traffic requires using WPA2/WPA3 encryption on Wi-Fi networks, avoiding unencrypted plaintext transmissions, and utilizing VPNs over untrusted public access points.

## Quick Review Reference

* **Tethering:** Sharing a mobile device's cellular connection with another PC or phone via Wi-Fi, Bluetooth, or USB.
* **Discoverable Mode:** Transmits device name, class, and supported technical features so other Bluetooth devices can locate and request pairing.
* **Manual Wi-Fi Setup:** Requires typing the exact network name (**SSID**) and network password when hidden networks do not broadcast publicly.
