# Home Network Basics

---

## Home Integrated Router Layout

A typical home router acts as a multi-purpose device combining a router, a switch, and a wireless access point:

| Port / Interface | Label / Name | Function | Network Assignment |
|---|---|---|---|
| **Ethernet Ports** | LAN | Connects wired local devices (PCs, TVs, printers) | Internal local network (same network as Wi-Fi) |
| **Internet Port** | WAN / Internet | Connects to cable/DSL modem or ISP link | External network (separate from local network) |
| **Wireless Antenna** | Wi-Fi Access Point | Connects mobile and wireless smart home devices | Internal local network (same network as LAN ports) |

```text
[ Home Devices (LAN / Wi-Fi) ] ---> [ Integrated Router ] ---> [ Internet Port (WAN) ] ---> [ Modem / ISP ]
```

> **Security Note:** Because Wi-Fi devices share the same local network as wired Ethernet ports by default, an compromised IoT device (like a smart bulb or camera) can easily scan and attack other PCs or NAS drives on the same internal LAN.

## Connected Home Devices

Home networks handle an increasing variety of endpoints beyond standard computers:

* **Entertainment:** Smart TVs, gaming consoles, media streamers.
* **Smart Home & Automation:** Climate control thermostats, smart lighting, security cameras.
* **Peripherals:** Printers, scanners, network storage (NAS), IP phones.

---

## Quick Quiz Notes
- **Integrated Routers:** Home routers provide both wired and wireless access in a single box; a separate wireless access point is usually not required.
- **Ethernet (LAN) Ports:** Used to connect local wired devices directly to the router's internal switch.
