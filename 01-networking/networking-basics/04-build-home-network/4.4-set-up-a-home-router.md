# Set Up a Home Router

---

## Physical Setup & Connection Types

Before accessing the router configuration interface, physical media must be correctly connected based on the ISP delivery mechanism:

| Connection Type | Physical Port / Cable | Function |
|---|---|---|
| **Cable Internet** | Coaxial cable with BNC / F-type connector | Connects cable modem to service provider splitter |
| **DSL Internet** | Telephone-type cable (RJ-11 connector) | Connects DSL modem to wall telephone jack |
| **Wired LAN** | Ethernet Patch Cable (UTP with RJ-45) | Connects PCs, switches, and laptops to router LAN ports |
| **WAN / Internet Port** | RJ-45 Ethernet Port | Connects integrated router to external modem (if separate) |

---

## Initial Router Configuration Workflow

<Sequence>
  <Step title="1. Establish Physical & IP Connection" subtitle="Local Connection">
    Connect PC to a router LAN port using a straight-through Ethernet cable. Enable **DHCP** on the PC to automatically lease an IP address and retrieve the **Default Gateway** address (e.g., `192.168.0.1`).
  </Step>
  <Step title="2. Access GUI & Secure Admin Credentials" subtitle="Management Access">
    Enter the default gateway IP into a web browser. Log in using default credentials (e.g., `admin`/`admin`). Immediately change the administrator password under management settings to prevent unauthorized local admin access.
  </Step>
  <Step title="3. Configure Wireless (WLAN) Settings" subtitle="Radio & SSID Setup">
    Enable desired radio frequencies (e.g., 2.4 GHz / 5 GHz). Set a custom **SSID** (avoid revealing device brand/model). Adjust maximum user thresholds or DHCP pools as needed.
  </Step>
  <Step title="4. Implement Wireless Security" subtitle="Encryption Setup">
    Select **WPA2-Personal** (or WPA3) encryption mode. Define a strong pre-shared key (passphrase) to secure radio transmissions.
  </Step>
  <Step title="5. Connect Wireless Clients & Verify" subtitle="Client Onboarding">
    Use client software (e.g., PC Wireless utility) to discover the SSID, enter the passphrase, confirm association, and test end-to-end connectivity via web browsing or ICMP (`ping`).
  </Step>
</Sequence>

> **Security Note:** Default credentials (`admin`/`admin`) are publicly listed in vendor documentation. In real-world security audits, unmanaged home routers running default login credentials remain one of the primary targets for botnet recruitment and local network compromise.

## Key Takeaways from Packet Tracer Activity

* **DHCP Auto-Configuration:** Switching endpoints from static to DHCP allows automatic assignment of IP addresses, subnet masks, default gateways, and DNS servers.
* **Gateway IP Discovery:** A client's default gateway address doubles as the web management IP for the integrated router.
* **Pre-Shared Key (PSK):** WPA2-Personal requires matching passphrases on both the access point and client radio adapters to complete the 4-way handshake and allow traffic flow.
