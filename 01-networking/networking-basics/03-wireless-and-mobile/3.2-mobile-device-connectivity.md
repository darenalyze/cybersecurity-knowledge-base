# Mobile Device Connectivity

---

## Wi-Fi vs. Cellular Connections

| Connection Type | Benefits | Configuration / Details |
|---|---|---|
| **Wi-Fi** | Faster, uses less power, does not use cellular data | Auto-connects to saved networks. Unbroadcasted SSIDs require manual setup. |
| **Cellular Data** | Works anywhere with tower signal (4G/5G) | Switches automatically between 4G/3G/5G; often has data limits or extra fees. |

> **Security Note:** Public Wi-Fi sends unencrypted data easily captured by rogue access points. Always enforce WPA2/WPA3 encryption, avoid typing plaintext passwords, and use a VPN on public networks.

---

## Manual Wi-Fi Setup Steps

If an access point hides its SSID name, you must manually configure the connection:

* **Android:** `Settings` > `Add network` > Enter SSID > Select Security Type > Enter Password > `Save`
* **iOS:** `Settings` > `Wi-Fi` > `Other` > Enter SSID > Select Security Type > Enter Password > `Join`

## Bluetooth & Pairing

Bluetooth connects up to **8 devices** simultaneously using low-power, short-range radio signals for tasks like headsets, wireless mice, or tethering.

```text
[ Nearby Device ] ---> Set to "Discoverable Mode" (Transmits Name/Class)
                              |
[ Mobile Device ] ---> Scan for Devices -> Select Device -> Enter PIN -> Connected
```

---

## Quick Quiz Notes
- **Power Conservation:** Connecting to Wi-Fi consumes less battery than keeping cellular radios active.
- **Tethering:** Sharing a mobile device's internet connection with another device via Bluetooth, Wi-Fi, or USB.
- **Discoverable Mode:** The state a Bluetooth device must enter so other devices can locate and request a connection.
