## Module Overview & Key Takeaways

Module 04 covers the core architecture, wireless standards, and initial setup procedures required to deploy and secure a home Local Area Network (LAN). 

```
  +-------------------------------------------------------------------+
  |                       INTERNET (WAN)                              |
  +-------------------------------------------------------------------+
                                    |
                          [ Modem (Cable / DSL) ]
                                    |
                            (WAN / Internet Port)
                                    |
                +---------------------------------------+
                |        Integrated Home Router         |
                |   (Switch + AP + Router + Firewall)   |
                +---------------------------------------+
                   /                |                \
                  /                 |                 \
          (2.4 GHz / 5 GHz)    (Ethernet Ports)   (Guest SSID)
                /                   |                 \
        [ Wireless Clients ]  [ Wired LAN Devices ]  [ Visitor Devices ]
        (Laptops, Smart TV)   (Desktop PCs, NAS)     (Internet Only)
```

### Core Concepts Matrix

| Area | Focus | Key Operational Details |
|---|---|---|
| **Network Architecture** | Integrated Router | Combines an Ethernet switch, Wi-Fi Access Point (AP), router, DHCP server, and NAT/firewall into a single chassis. |
| **Wireless Bands** | 2.4 GHz vs 5 GHz | **2.4 GHz:** Better range/wall penetration, higher congestion. <br> **5 GHz:** Higher data rates, shorter range, less interference. |
| **Standards & Bodies** | IEEE vs. Wi-Fi Alliance | **IEEE (802.11):** Writes technical specifications. <br> **Wi-Fi Alliance:** Certifies multi-vendor hardware interoperability. |
| **Physical Layer** | Cabling Options | **Cat 5e (UTP):** 4 twisted pairs for standard LANs. <br> **Coaxial / RJ-11:** WAN connection to modems. |
| **Security Controls** | Access & Encryption | **WPA2/WPA3:** True data protection. <br> **Guest SSID:** Isolates visitors to Internet-only access. <br> **SSID Hiding / MAC Filtering:** Minor friction, not real security. |

### Question 5: Visitor Access & Internet Isolation
* **Your Selection:** *Authentication*
* **Correct Answer:** **Guest SSID**
* **Security & Operational Context:** 
  * A **Guest SSID** creates a secondary, logically isolated wireless network on the same access point.
  * Traffic on the Guest SSID is routed straight out the **WAN interface (Internet)**, blocking client-to-client communication with the primary LAN. This protects private shares, printers, and internal devices from untrusted visitor hardware.
  * While *authentication* (entering a password) grants access to a network, it does not inherently limit or restrict where those devices can route once connected.

## Quick Review Checklist

- [x] **Ethernet vs. Internet Port:** Ethernet (LAN) ports connect local devices; the Internet (WAN) port connects to the external modem/ISP line.
- [x] **SSID Characteristics:** Case-sensitive, alphanumeric string up to 32 characters long sent in frame headers.
- [x] **Unlicensed Bands:** 2.4 GHz and 5 GHz bands can be used publicly without government license requirements.
- [x] **Mixed Mode:** Enables backward compatibility for legacy devices (802.11b/g) at the cost of overall maximum network throughput.
