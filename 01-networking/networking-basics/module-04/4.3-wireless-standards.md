# 4.3 Wireless Standards

---

## IEEE vs. Wi-Fi Alliance

Two primary organizations drive wireless LAN connectivity and interoperability:

| Organization | Primary Role | Key Output / Standards |
|---|---|---|
| **IEEE** | Creates technical specifications and radio frequency (RF) standards | IEEE 802.11 suite (governs WLANs across 2.4 GHz & 5 GHz) |
| **Wi-Fi Alliance** | Tests and certifies hardware across manufacturers for compatibility | "Wi-Fi Certified" seal on consumer devices |

---

## Wireless Router Settings

Configuring a wireless access point involves four core parameters:

| Setting | Function | Security / Operational Context |
|---|---|---|
| **Network Mode** | Sets supported 802.11 standards (e.g., 802.11n, 802.11ac, or Mixed) | **Mixed Mode** supports legacy devices, but running purely newer standards gives maximum throughput. |
| **SSID (Service Set ID)** | Alphanumeric name (up to 32 chars) identifying the specific WLAN | Case-sensitive string transmitted in wireless frame headers to direct traffic. |
| **Standard Channel** | Dictates the exact radio frequency channel used for transmission | Usually set to **Auto** so the AP picks the least congested channel. |
| **SSID Broadcast** | Controls whether the AP advertises its SSID publicly | Disabling it forces manual entry on clients, but offers **no real security** on its own. |

> **Security Note:** Hiding your SSID (disabling broadcast) is security through obscurity. Attackers using basic wireless sniffers (like Kismet or Wireshark) can easily capture the SSID from unencrypted probe request/response frames sent during device association.

## Quick Quiz Notes
- **SSID:** Service Set Identifier used to name and distinguish a specific wireless network.
- **Mixed Mode:** Allows legacy devices using older 802.11 standards to connect to the network alongside newer devices.
- **Wi-Fi Alliance:** Industry trade association that tests and certifies wireless equipment for inter-vendor compatibility.
