# Encapsulation and the Ethernet Frame

---

## Ethernet Frame Basics

* **Ethernet:** Popular technology for local area networks (LAN).
* **Ethernet NIC:** Hardware card used by devices to connect to the network.
* **MAC Address:** Unique **hardware address** burned permanently into every NIC.
* **Header Fields:** Every Ethernet frame includes **Source MAC** and **Destination MAC**.

> **Security Note:** MAC addresses can be spoofed (faked) using software. Never rely solely on MAC addresses for strong access control or user authentication.

---

## Encapsulation

**Encapsulation** is wrapping network data inside a specific container (**frame**) so it can travel across a network.

### How It Works

* **Encapsulation (Sending):** Wrapping data inside a header/trailer.
* **De-encapsulation (Receiving):** Stripping away the headers to read the inner data.
* **Frame:** Network container that acts like an envelope carrying source and destination addresses.

```
+---------------------------------------------------------+
|                  ENVELOPE (Frame Header)                |
|  [ Destination MAC/IP ]  +  [ Source MAC/IP ]            |
|                                                         |
|    +-----------------------------------------------+    |
|    |               LETTER (Payload / Data)         |    |
|    +-----------------------------------------------+    |
+---------------------------------------------------------+
```

### Simple Analogy

| Physical Letter | Computer Network |
| :--- | :--- |
| **Letter Content** | Data / Message Payload |
| **Envelope** | Ethernet Frame / IP Packet |
| **Street Address** | MAC Address / IP Address |
| **Packing Letter** | **Encapsulation** |
| **Opening Letter** | **De-encapsulation** |

## IP Packet Structure (IPv6 Example)

Network packets require standardized fields to reach their destination across multiple networks.

```
+-------------------------------------------------------------+
|                     IPv6 Packet (40 Bytes)                  |
+-------------+-----------------+-----------------------------+
| Version     | Traffic Class   | Flow Label                  |
+-------------+-----------------+-----------------------------+
| Payload Length                | Next Header  | Hop Limit    |
+-------------------------------+--------------+--------------+
| Source IP Address                                           |
+-------------------------------------------------------------+
| Destination IP Address                                      |
+-------------------------------------------------------------+
```

* **Key Responsibility:** **IP (Internet Protocol)** ensures packets move from source to destination across different networks.
* **Crucial Fields:** **Source IP** (who sent it) and **Destination IP** (where it goes).

> **Security Note:** Unencrypted IP packets reveal source/destination traffic patterns and data. Always use encrypted protocols (like HTTPS or VPNs) to protect payload privacy.
